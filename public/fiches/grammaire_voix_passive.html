💡 Synthèse interactive

Découvre la différence entre voix active et passive avant de commencer le jeu !

Sujet Actif

La Voix Active

Le sujet fait l'action exprimée par le verbe. La phrase a généralement un CDV (Complément Direct du Verbe).

Exemple :
"Le chat poursuit la souris."
(Le chat fait l'action de poursuivre)
Sujet Passif

La Voix Passive

Le sujet subit l'action. Le verbe se forme avec l'auxiliaire être + le participe passé (s'accorde avec le sujet).

Exemple :
"La souris est poursuivie par le chat."
(La souris subit l'action)
Qui fait l'action

Le Complément d'Agent

Dans une phrase passive, il désigne l'auteur réel de l'action. Il commence souvent par la préposition par (ou de).

Exemple :
"La souris est poursuivie par le chat."
(par le chat fait réellement l'action)

🔄 Règle d'or : Le temps de l'auxiliaire "être"

Lorsqu'on transforme une phrase active en phrase passive, l'auxiliaire être doit être conjugué au même temps que le verbe actif :

Présent actif ➔ Présent passif :
"Le chat poursuit..." ➔ "... est poursuivie."
Passé composé actif ➔ Passé composé passif :
"Le chat a poursuivi..." ➔ "... a été poursuivie."
Futur actif ➔ Futur passif :
"Le chat poursuivra..." ➔ "... sera poursuivie."
